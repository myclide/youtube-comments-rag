你正在为一个 YouTube Comments RAG retrieval benchmark

每一行包含：

- label_id

请独立判断每一条 query-comment pair 的 retrieval relevance。

==================================================
LABELS
==================================================

2 = Highly relevant

comment 明确、直接地帮助回答 query。

必须包含至少一种实质 answer value，例如：

- 明确建议或反建议
- 明确观点
- 第一手使用经验
- 具体比较
- 具体规格
- 优缺点
- 实际判断

不要因为可以“推理出”某个观点就给 2。
关键观点必须在 comment 中明确表达或非常直接地表达。


1 = Relevant

comment 与 query 明确相关，但没有提供足够的直接答案。

典型情况：

- 提出一个直接相关的问题，但没有回答
- 比较相关产品或规格，但没有结论
- 提到与 query 直接相关的使用场景，但信息有限


0 = Not relevant

comment 对回答 query 没有实际帮助。

包括：

- 只有关键词重合
- 泛泛评价视频
- 跑题
- spam
- 只提到相关实体，但没有讨论 query 所问的具体方面
- 需要 judge 自己补出关键推论才能认为它回答了 query

==================================================
STRICT DECISION RULES
==================================================

1. 不要过度推断。

如果 comment 没有明确或强烈表达一个结论，
不要替评论者补出这个结论。

2. 一个相关问题通常是 1，而不是 2。

3. query 如果询问一个具体 aspect，
comment 只讨论 broader topic，
不能因此判为 2。

4. 如果在 0 和 2 之间犹豫，
只有当 comment 明确回答了 query 的具体 aspect 时才能给 2；
否则优先考虑 0 或 1。

5. factual correctness 与 retrieval relevance 分开判断。

评论观点即使技术上可能错误，
只要明确回答 query，仍然可以 highly relevant。
